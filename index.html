Multi-Scale Elastostatics Visualizer

Static snapshot of the Multi-Scale Elastostatics Visualizer (msev 0.2.0). Scenario: a 1 m glass/epoxy bar (A = 1000 mm², layers stacked along the axis, Vf = 0.5), clamped at x = 0, tip load 10 kN plus a distributed load of 5 kN/m.

The unit cell gives Eeff = 6.68 GPa (Reuss bound 6.68 GPa, Voigt bound 37.8 GPa). The homogenized bar is compared with a fully resolved model of 5 cells. For interactive parameters run streamlit run app.py.
